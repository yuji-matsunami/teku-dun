# teku-dun

歩くことを楽しみに変え、日々の運動習慣を支える冒険RPGアプリです。

## 開発者向け

macOS + Android のローカル開発、API疎通、生成コード更新、検証手順は
[開発手順](docs/development.md)を参照してください。

開発コマンドはリポジトリルートの`Taskfile.yml`で管理しています。go-taskを
インストールした後、`task --list`で利用可能なタスクを確認できます。
