# MVPスコープ

## MVPの目的

「ゲームの続きを進めたいから短い散歩に出かける」という体験が成立するかを検証する。

MVPでは機能数を増やすことより、次の一連の体験を完成させることを優先する。

1. 自分の冒険者を作る
2. 散歩前にミッションと装備を選ぶ
3. 目的地へ向かう、または自由に歩く
4. 歩行中に探索と自動戦闘が進む
5. 装備や素材を獲得する
6. 不要な装備をコインへ変換する
7. 装備を購入・強化して強敵へ再挑戦する
8. 期限内に強敵を倒す

## 想定する利用時間

主に10〜15分程度の軽い散歩を想定する。通勤、買い物、昼休みなどの日常的な徒歩移動でも進行できるようにする。

具体的な歩数、距離、時間の判定値は、詳細設計と検証を通じて決定する。

## MVPに含めるもの

### アバター

- 自分の分身となる冒険者の作成
- 最低限の外見カスタマイズ
- 冒険者レベルと基礎能力
- 職業は設けない

### 移動とマップ

- 現在地周辺のマップ表示
- 目的地型ミッション
- 自由歩行型ミッション
- 徒歩移動の記録
- 目的地への到着判定
- 自宅周辺でも遊べる目的地生成
- 移動中の操作を必要としない進行

### ミッション

- 短時間で完了できるミッションの提示
- 宝箱の回収
- 素材の採取
- 通常敵の討伐
- 強敵への挑戦

ミッションの具体的な種類、生成条件、歩数、距離、時間などの数値は詳細設計で決定する。

### 戦闘

- 戦闘の自動処理
- 装備性能と敵との相性による勝敗計算
- 通常敵との戦闘
- 一人で挑戦する強敵
- 強敵へ与えたダメージの蓄積
- 強敵ごとの討伐期限

歩行中に立ち止まったり、画面を注視したりする操作は設けない。

### 装備

- 武器、頭防具、胴防具、アクセサリー
- 通常敵や宝箱からの通常装備ドロップ
- 装備の属性や固有効果
- 装備の変更
- コインを使った装備強化
- 強敵の素材と設計図を使った強力な装備の制作

武器の種類や属性数など、コンテンツ量に関する具体値は別途決定する。

### コインとショップ

- 不要装備の売却
- 売却によるコイン獲得
- コインを使った装備強化
- コインを使った通常装備の購入
- ゲーム内の行動によるコイン獲得

MVPではコインを課金販売しない。

### 継続記録

- 毎日歩いた実績の連続日数表示
- 連続日数の自己ベスト表示
- 記録が途切れてもゲーム進行を失わない設計

一日を達成と判定する具体的な歩数、距離、時間などは後で決定する。

### 安全性とプライバシー

- 移動中の操作を要求しないUI
- 目的地到着時の自動判定と自動取得
- 危険な場所や立入禁止区域を避けるための考慮
- 自宅などの正確な位置情報を他人へ公開しない設計
- 車や電車による移動を徒歩として扱わないための考慮

## MVPに含めないもの

- 周回ルートの自動生成
- メインストーリー
- NPCや会話イベント
- 職業システム
- 手動またはリアルタイムの戦闘操作
- フレンド、ギルド、ランキング
- 他プレイヤーとの協力討伐や対人戦
- 観光地や店舗と連携した特別ミッション
- 有料通貨やコインの課金販売
- 歩行を促す通知
- 週間目標
- 連続記録が途切れた場合のゲーム内ペナルティ

## 将来追加を検討するもの

- 周回型の散歩モード
- メインストーリーと世界設定
- 地域ごとの物語やイベント
- NPC
- ソーシャル機能
- 協力型の強敵討伐
- 長距離ウォーキングや遠征向けモード
- 装備セットの保存
- 外見アイテムの拡充
- 通知や週間目標などの習慣化支援
- 収益化の仕組み

## 未決事項

以下は方向性を変えるものではなく、プロトタイプ制作やバランス調整の段階で決定する。

- 一日を「歩いた」とする判定条件
- 目的地までの標準距離と到着判定範囲
- 自由歩行型で報酬が発生する条件
- ミッションの種類と生成ルール
- 強敵の討伐期限、体力、報酬、期限切れ時の詳細
- 主人公レベルと装備性能の関係
- 武器タイプ、属性、レアリティの種類
- 装備の強化上限と必要コイン
- ショップの商品構成と更新方法
- ドロップ率、売却価格、購入価格
- アバターで選択できる外見項目
- 位置情報、歩数、移動速度を取得する技術方式

## MVPの成立条件

少なくとも、次の状態を確認できたときにMVPの中心体験が成立したと判断する。

- ユーザーが短い散歩を始める理由としてミッションが機能する
- 歩行中に画面操作をしなくても冒険が成立する
- 散歩後に装備や素材を得た満足感がある
- 欲しい装備や強敵が、次の散歩の理由になる
- 装備の売却、購入、強化が分かりやすく循環する
- 数日間の散歩によって強敵を倒せる
- ストーリーがなくても装備収集と育成を続けたいと感じられる
